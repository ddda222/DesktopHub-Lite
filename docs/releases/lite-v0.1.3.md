# DesktopHub Lite 0.1.3

Windows 10/11 x64 便携版。下载 ZIP，完整解压到固定位置，再运行 `DesktopHub-Lite.exe`。ZIP 包含 WebView2 加载器和智能体接入文件。

- 在「设置 → 邮箱通知」绑定 QQ 邮箱或 Gmail。灵动岛支持复制验证码、复制链接和打开网页。
- 在「设置 → 智能体连接」手动检测 Codex 和 DSH，查看连接状态并添加接入。
- 灵动岛翻译默认中译英，点中间按钮可交换方向。翻译和剪贴板 AI 解读期间可移开鼠标继续阅读。
- 在「设置 → 应用管理 → 添加应用」导入桌面快捷方式或勾选 Windows 系统应用，按当前分类添加。
- 通用设置提供当前 Windows 用户的登录自启开关。升级前先从托盘退出旧版，备份并保留便携目录里的 `data`。
