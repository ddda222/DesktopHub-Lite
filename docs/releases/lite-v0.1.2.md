# DesktopHub Lite 0.1.2

Windows x64 便携版。本次加入原生对照台、应用声音调音台和配置导出恢复，整理设置布局，并修复快速操作时的状态与保存问题。

## 更新内容

- 原导航右侧只增加「对照台、调音台」，工作台已移除。对照支持图片／文字、擦除和差异视图、文件中转 A/B，以及最多四个可置顶的独立窗口；关闭即释放内存快照。
- 调音台读取 Windows Core Audio 应用会话，支持单应用音量、静音和手动声音配置；写入后读回系统状态，连续调整按顺序合并，打开页面不会自动套用配置。
- 通用设置增加「配置备份」：导出应用、分类和显示偏好；导入先严格校验、展示数量／差异／失效路径，再由用户确认。可靠备份后应用，写入失败回滚，中断后启动恢复。旧的空／失效分类只在导出副本中规范为未分类，不修改原清单。
- 配置不包含 API 密钥、翻译参数、剪贴板、图片／文件正文、声音配置或系统联动开关；路径只是本机引用。导入不启动目标，不删除原文件，不丢弃尚未保存的应用／灵动岛草稿。
- 应用管理增加分类归属、分组、筛选、搜索、组内排序和完整目标查看；设置保留草稿、保存反馈和键盘焦点。
- 保留 06 光轨舱门、实底主题与现有控件外观。快速开合从当前状态接续，正文不缩放；减少画布重新分配，拖动不再逐帧修改向下继承的样式变量。减少动画模式停用装饰动画。
- 修复保存失败后内存仍变化、重复启动请求、迟到翻译设置响应、清空剪贴板响应遮住新记录、重复文件添加、删除当前分类后选择失效等问题。

## 下载与升级

下载 `DesktopHub-Lite-0.1.2-win-x64.zip`，完整解压后运行 `DesktopHub-Lite.exe`。支持 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime，不需要 Node.js、Rust 或 .NET。

从托盘退出旧 Lite，备份原目录后覆盖新版程序文件，保留 `data/` 与 `portable.flag`。翻译密钥仍保存在当前 Windows 用户的凭据管理器。不要同时运行两个版本；旧 WPF 与 Lite 不自动互迁数据。包内元数据记录源码提交，同页 SHA256SUMS 可核验完整性。

## 验证范围与限制

已覆盖隔离配置校验、备份失败、写入回滚、中断恢复、旧分类兼容、过期预览及状态竞态；网页检查恢复取消／确认、草稿保护、焦点、窄窗口和减少动画。动画压力场景的画布尺寸写入由 72 次降至 8 次，该结果不代表原生帧率提升。

真实音量写入、系统混音器双向同步、设备切换、多屏／高 DPI、独立窗口置顶、屏幕共享隐藏及真实翻译服务仍需按实际环境验证；网页模拟和构建通过不能代替这些实测。本轮不读取真实剪贴板或密钥、不修改真实音量。此版本未签名，不自动安装更新。
