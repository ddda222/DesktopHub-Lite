# DesktopHub Lite 0.1.1

Windows x64 便携版。本次更新完善任务状态、文件中转和图片预览，并让细线在最大化／全屏时也能通过鼠标移入立即展开。

## 更新内容

- 任务状态胶囊显示翻译中、操作结果、暂停记录和暂存数量；WebGL 用短暂边缘光效提示状态变化。
- 文件中转支持图片／文本预览、失效提示和最近 10 次移出撤销；移出只删除引用，保留原文件。
- 图片预览提供完整画布、原尺寸查看和折叠文件信息；独立图片窗口优化缩放、置顶状态和深浅主题。
- 最大化／全屏细线支持鼠标移入立即展开，移开恢复细线，悬停不抢前台焦点。
- 新增“在截图和屏幕共享中隐藏灵动岛”开关，默认关闭，与 WebGL 独立。
- 开发网页增加任务、预览和撤销测试入口，演示数据不读取本机文件。

## 下载与运行

下载 `DesktopHub-Lite-0.1.1-win-x64.zip`，完整解压后运行 `DesktopHub-Lite.exe`。支持 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime；前端资源已内置，不需要 Node.js、Rust 或 .NET。

压缩包附带使用说明、更新说明和源码版本信息；同页 `SHA256SUMS.txt` 可核对文件完整性。

## 升级并保留数据

从托盘退出旧 Lite，备份原程序目录，再将新包的程序文件覆盖到原目录，保留原有 `data/` 和 `portable.flag`。不要让两个版本同时运行。翻译密钥仍保留在当前 Windows 用户的凭据管理器中。旧 WPF v1.0.0 与 Lite 为不同版本线，不自动迁移其数据。

## 使用范围

- 图片预览上限 8 MiB，文本最多预览前 64 KiB；不支持的格式仅显示基本信息。
- 共享隐藏仅作用于灵动岛，独立图片、设置和翻译窗口仍可见。具体会议／远程软件是否遵守 Windows 捕获排除设置，需要实测；远程操作时自己也可能看不到灵动岛，可从托盘设置关闭。
- 多屏、高 DPI、游戏全屏、实际屏幕共享和真实翻译服务仍需按使用环境验证。网页中的置顶演示不代表系统置顶效果。
- 此版本未做代码签名，自动下载安装更新未启用。仓库中的旧 WPF 发布不作为 Lite 更新包。
